# Procedure: how this skill grades a plan package

## Read order

1. Resolve the package ID or issue URL. In live mode enforce the repo and house rules in scope.md. In eval mode work from the supplied snapshot only.
2. Read the issue, thread, and repo facts. Record the behavior to change, the user's expected outcome, and explicit constraints.
3. Read the reproduction evidence. Record the setup, trigger, and observation before treating any proposed cause as established. In live mode use the student's posted reproduction or the quoted house evidence.
4. Read the whole plan and comment. Record diagnosis, scope, first implementation action, intended remedy, tests, unknowns, and stated commitments.

## Evidence gathering

1. Use the evidence guide to pair each rubric row with the required source text. For grounding and remedy, compare the diagnosis and remedy with the repro trigger and output.
2. For scope and execution, compare changes and starting points with the issue. For verification, record an action, an input or referenced repro, and its observable outcome.
3. For honesty, tag uncertain claims and look for a stated check that resolves them. For thread and repo fit, match concrete requests and policies against the comment and plan.

## Check execution

Grade each rubric row in table order. Reuse gathered facts while keeping each check independent. Grade pass when its condition is met, fail when the evidence contradicts it, and unclear when an evidence gap prevents deciding after a targeted reread. Record a short quotation or concrete observation per row. Apply the voice guide in live mode only and report divergences according to the skill.

## Verdict assembly

Apply the rubric's verdict rule to all row grades. Explain any failed or unclear deciding check with its evidence. Finish with the JSON schema requested by SKILL.md, using the bundle ID or issue URL as item.
